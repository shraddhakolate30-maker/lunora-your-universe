# 🌌 LUNORA — Your Space. Your Universe.

> A little space for your thoughts, feelings, memories, and everyday choices.

LUNORA is a personal, cosmic-themed web experience designed to make everyday moments feel simpler and more meaningful. It brings together playful decision-making and personal reflection in one universe-inspired interface.

Sometimes, even small decisions take too much time. LUNORA offers a simple way to explore your options, make a choice, and move forward—one little moment at a time.
 ✨ Features

### 🪐 Cosmic Choices

Explore a playful way to make everyday decisions. Use Yes/No options or create your own choices.

### 🌙 Secret Chit

Pick one of two mysterious cosmic chits without seeing the hidden options. Select a chit and reveal its result through an interactive experience.

### 💫 My Feelings

Create space to acknowledge your feelings and reflect on your day.

### ⭐ My Stars

Give your thoughts a place in your personal universe.

### 📖 Cosmic Journal

Keep personal reflections and memories together.

### 🎵 Cosmic Atmosphere

Explore a space-inspired atmosphere designed to make the experience feel calm and immersive.

*Feature availability may depend on the current implementation.*

## 🎯 The Idea Behind LUNORA

LUNORA explores a simple idea: not every small decision needs to become a big task.

Instead of creating another productivity tool that demands more attention, I wanted to build a small digital universe where users can handle everyday choices and make room for personal reflection.

The goal is to combine simplicity, creativity, and a cosmic visual experience.

## 🚀 Getting Started

### Prerequisites

* Node.js
* npm

### Installation

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd lunora-your-universe
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🔐 Privacy

Personal thoughts and journal entries can be sensitive. Review the application's actual storage and data-handling implementation before entering private information.

Do not commit API keys, passwords, access tokens, or other secrets to this repository.
